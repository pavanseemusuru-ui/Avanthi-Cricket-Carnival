# Avanthi-Cricket-Carnival

Auction website for the Avanthi Cricket Carnival.

## Run locally

Create a PostgreSQL database, copy `backend/.env.example` to `backend/.env`, and set `DATABASE_URL` to your PostgreSQL connection URL along with the local account credentials and secret. Then run `npm run dev` from this directory. The frontend is served at `http://localhost:3000`.

See [DEPLOYMENT.md](DEPLOYMENT.md) for production configuration, security requirements, and release checks.
